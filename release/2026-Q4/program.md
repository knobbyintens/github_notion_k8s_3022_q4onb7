# Q4 2026 Service Onboarding Program

The Q4 2026 onboarding wave covers services approved in the service
certification register. Onboarding outcomes (deployed, deferred or
blocked) are recorded per service in the receipts database kept in the
platform workspace, in the operator report, and in the program audit file
at `release/2026-Q4/onboarding-audit.json`.

The audit file is a snapshot of the whole wave: it must list every
service in scope, including those that could not be onboarded.
